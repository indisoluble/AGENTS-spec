# 01 — Discovery

Discovery asks what a requester needs from a coding agent and why. The product being explored is the operating contract, the instructions an agent follows while working on a project. Start with a need, feedback or an observation, including something learned while trying the instructions. Describe a situation where it matters, then vary one condition. Would the requester expect the agent to act differently?

| Read in this order | What you will find |
| --- | --- |
| [Objectives and rationale](deliverables/objectives-and-rationale.md) | The outcomes the requester values, their priority and the reasons behind them. |
| [Questions and requester conclusions](deliverables/open-questions.md) | What the requester has settled, its scope, and any outcomes that still need a decision. |
| [Proposed examples](deliverables/example-coverage.md) | Cases grouped by subject. Each has a stable, subject-scoped EX identifier, starting conditions, an action and an observable outcome for discussion. |

Discovery owns these objectives, reasons, proposals and questions. The requester or an explicitly authorized delegate decides product outcomes and priorities. A *defining example* is a particular case they expressly agree should determine what counts as correct in its circumstances. Agreeing on an outcome can settle a question while the example remains proposed. The [Discovery procedure](docs/maintaining-discovery.md) explains how to add a case and record what the requester settled or left open.
