# 02 — Design

Design selects mechanisms and rationale for realizing [accepted product intent and constraints](../01-behavior/deliverables/baseline.md). Start with [contract design](deliverables/contract-design.md) for boundaries, vocabulary, layer composition, the clause-to-requirement index, and links to detailed mechanisms, delivery, and methods.

`deliverables/` keeps selected prescriptions with their explanations. Supporting `docs/` contains [decisions and alternatives](docs/decisions-and-alternatives.md) and [review guidance with 28 non-normative illustrations](docs/design-review.md).

The [staged contract](../03-contract/prerelease_AGENTS.md) contains the complete runtime instructions. [Shared authority and editing guidance](../docs/authority-and-change.md) governs maintenance and distinguishes design selection from product acceptance; the [project README](../README.md) locates other stages.
